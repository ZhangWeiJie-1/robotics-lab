## 发现与修复

1. 直接调用数学插件产生两套 Markdown 类型不兼容：改为 VitePress 原生 markdown.math=true，类型检查通过。
2. 图解 HTML 后缺少空行导致 C++ 代码被当作 HTML：修正 Markdown 边界，构建通过。
3. 默认英文分词遗漏连续中文中的关键词：独立审查复现“线程”零结果；加入同一份自包含 Han 字符/双字分词函数用于索引和查询，添加构建索引回归脚本。修复前失败、修复后及线上交互通过。
4. 首页缺少 main 语义标签：检查脚本发现后修复，再次验证通过。
5. 终端无 Git 推送凭据：通过已连接 GitHub 的树、提交与 ref 接口发布，没有创建或保存个人访问令牌。
