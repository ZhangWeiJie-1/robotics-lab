# 相机模型

> 初始学习笔记：核心说明与代码片段用于建立理解，未在本站环境验证机器人实验；“我的理解”和实验记录由本人继续补充。

## 1. 学习目标
把像素、归一化平面与相机坐标连接起来。

## 2. 核心原理
相机内参已知，像素不等于三维点；RGB-D 深度通常表示光轴方向的 Z，必须核对设备接口。

## 3. 公式推导
从本节的观测模型出发，先明确坐标系与变量，再使用下面的核心关系：

$$
u=f_xX/Z+c_x,\quad v=f_yY/Z+c_y
$$

推导练习：标出已知量、未知量和矩阵维度；选择一个简单数值例子检查单位与方向。完整手写推导待补充。

## 5. C++ / Python 代码
```cpp
double x = (u - cx) * depth / fx;
double y = (v - cy) * depth / fy;
```
