# ICP 与 3D–3D 配准

> 初始学习笔记：核心说明与代码片段用于建立理解，未在本站环境验证机器人实验；“我的理解”和实验记录由本人继续补充。

## 1. 学习目标
理解两帧 RGB-D 配对点为什么属于不同坐标系。

## 2. 核心原理
同一空间点在两帧中的坐标通常不同。已知配对可求刚体变换；完整 ICP 还会迭代寻找对应。中心化后可通过 SVD 求旋转，并修正反射。

## 3. 公式推导
从本节的观测模型出发，先明确坐标系与变量，再使用下面的核心关系：

$$
\min_{R,t}\sum_i\|p_i-(Rq_i+t)\|^2
$$
