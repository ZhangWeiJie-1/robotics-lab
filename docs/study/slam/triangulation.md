# 三角测量

> 初始学习笔记：核心说明与代码片段用于建立理解，未在本站环境验证机器人实验；“我的理解”和实验记录由本人继续补充。

## 1. 学习目标
观察基线、视差与深度不确定性的关系。

## 2. 核心原理
该简式适用于校正后的平行双目：f 用像素，B 和 Z 用同一长度单位。一般位姿下用投影矩阵建立齐次线性方程。

## 3. 公式推导
从本节的观测模型出发，先明确坐标系与变量，再使用下面的核心关系：

$$
Z=\frac{fB}{d},\quad |\delta Z|\approx\frac{Z^2}{fB}|\delta d|
$$

推导练习：标出已知量、未知量和矩阵维度；选择一个简单数值例子检查单位与方向。完整手写推导待补充。

## 5. C++ / Python 代码
```cpp
double f = 500.0, B = 0.1, disparity = 25.0;
double Z = f * B / disparity; // 2.0 m
```
