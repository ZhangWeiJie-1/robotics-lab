# 关于我

我是一名关注机器人自主导航与视觉 SLAM 的硕士研究生。Robotics Lab 是我的学习、实验与项目记录空间，也是一份持续更新的技术作品集。

## 研究兴趣
- 校园、园区与人行道等低速移动机器人场景。
- RGB-D 视觉感知、定位与导航。
- 机器人实物系统集成、跟随与动态环境避障。
