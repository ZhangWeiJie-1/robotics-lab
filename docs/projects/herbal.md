# 中草药智能识别系统

> 图像分类 · 桌面应用 · 历史成果展示

## 背景与目标
面向 24 类中草药图像分类，结合深度模型与 PyQt5 桌面界面，将训练实验转为支持图片、摄像头和本地视频的识别应用。项目用于图像分类与软件系统展示。

## 技术栈
ConvNeXt-Tiny · HAT · SCConv · PyTorch · OpenCV · PyQt5

## 开发过程
- 数据：24 类，输入尺寸 224×224×3，使用 train / valid / test 划分。
- 模型：以 ConvNeXt-Tiny 为主干开展模块改进，尝试过 VGG16、Swin、ASPP、FPN 等方案。
- 常用训练配置：30 epochs、batch=4、学习率 1e-3、AdamW、weight decay=0.01；最佳结果对应的精确配置待原始日志核对。
- GUI：欢迎页、主界面、视频界面；显示类别与置信度，后台线程执行识别，支持暂停与耗时显示。
