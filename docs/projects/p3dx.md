# P3-DX 移动机器人

> 研究载体 · 低速自主导航 · 依据已有运行记录整理

## 背景与目标
面向校园、园区和人行道场景，以 P3-DX 差速移动底盘为平台，逐步实现人员跟随、激光避障、地图定位与自主导航。当前重点是将已经运行的人员跟随系统接入 2D LiDAR 安全控制。

## 技术栈
ROS1 Noetic · Gazebo · rosaria · 2D LiDAR · PID · AMCL · move_base

## 常见问题
- `map ↔ base_footprint` TF 不连通：逐段确认发布者与时间源。
- `/RosAria/cmd_vel` 无发布者：检查控制节点与实际话题名称。
- 仿真中时间外推：确认 `/use_sim_time` 与 `/clock`。
- 狭窄场景避障容易卡住：记录状态切换与最小距离，再决定恢复策略。

## 后续计划与验收
1. 在仿真中验证障碍接近时减速、停车与恢复。
2. 实物低速验证；记录 `/scan`、`/odom`、`cmd_vel` 与时间戳。
3. 将人员跟随和导航的速度来源统一仲裁，避免同时控制底盘。
4. 建立最小距离、跟随误差、任务成功率与恢复次数指标。
