# RealSense D435 + YOLO

> 机器人感知 · RGB-D · 依据已有训练与运行记录整理

## 背景与目标
使用 RealSense D435 采集 RGB 与深度，通过自训练 YOLO 检测可乐罐，完成深度测距和相机坐标系下的三维位置恢复。后续扩展到两帧 RGB-D 视觉里程计。

## 技术栈
RealSense D435 · pyrealsense2 · Ultralytics YOLO · PyTorch · OpenCV · Python

D435 在本项目中按 RGB-D 相机使用，**不当作提供 IMU 数据的 D435i**。

## 三维恢复原理
对齐之后，以与图像流对应的内参恢复相机坐标：
$$X=(u-c_x)Z/f_x,\quad Y=(v-c_y)Z/f_y$$
需排除无效深度，在目标内部选取稳健区域，避免边缘混入背景。若使用 SDK 反投影接口，应使用匹配流的内参与畸变模型。

## 常见问题
- `cv2` 或 `pyrealsense2` 缺失：确认实际解释器与安装环境一致。
- 无图像输出：先用设备工具检查 USB 连接与流，再查 ROS 话题。
- 检测框中心深度不稳定：检查对齐、零深度、反射表面与背景污染。
- C++ librealsense 与 Python 包版本不同：记录版本并独立验证各自链路。
